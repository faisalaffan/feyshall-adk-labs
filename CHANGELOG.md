# Changelog

## [0.1.0] — 2026-05-28

### Added
- 55 recipes across 10 chapters covering ADK foundations through real-world use cases
- Dart ADK client library (`adk_client`) with REST wrapper and streaming support
- Flutter agent chat widget (`agent_chat`) with streaming, tool progress, and retry
- GitHub Actions CI/CD: eval, security scan, Dart, Go workflows
- Docker multi-stage build + docker-compose with full LGTM observability stack
- Helm chart for Kubernetes deployment (HPA, PDB, health checks)
- FastAPI entrypoint (`main.py`) with centralized config module
- MkDocs documentation site with Material theme
- Community health files: CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, SUPPORT
- Bilingual README (EN/ID) with badges and language switcher
- Evaluation test suites: safety, accuracy, prompt injection, regression
- git-crypt encryption for `docs/internal/`
- Makefile with 20+ targets for dev, test, lint, security, Docker
- Pre-commit hooks (ruff, mypy, gitleaks)
- Runnable Python code for 24+ recipes across all chapters
